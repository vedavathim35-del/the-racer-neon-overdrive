# THE RACER: OWN THE NIGHT — NEON OVERDRIVE
3D night street-racing game (Three.js r128, single HTML file). Gameathon 8.0.

## Play
Open `index.html` in Chrome/Edge (internet needed for the Three.js CDN), or use the GitHub Pages link.

## Controls
W/↑ gas · S/↓ brake/reverse · A/D steer · Space drift · Shift nitro · E camera · C look back · R reset · Esc pause · Enter start
